# Secure Note-Taking Application

A full-stack note-taking platform with **JWT Authentication**, **Role-Based Access Control** (User & Admin), MongoDB indexing, pagination, and aggregation pipelines.

Built as a technical assessment focusing on backend best practices.

---

## 🛠️ Tech Stack

**Backend:**  
Node.js, Express.js, MongoDB (Mongoose), JWT, Bcrypt

**Frontend:**  
Next.js 14, TypeScript, Tailwind CSS, Framer Motion, Axios
